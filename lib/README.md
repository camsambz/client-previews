# Animation libraries (pinned)

Shared by every client draft in this repo. Load with relative paths from a client folder, e.g. `../lib/gsap-3.15.1/gsap.min.js`.
Rules for using them: see `motion-standards.md` in the WEBSITE AUTOMATION project.

| Folder | Source | License |
|---|---|---|
| `lenis-1.3.27/` | https://github.com/darkroomengineering/lenis (npm `lenis@1.3.27`) | MIT, see `lenis-1.3.27/LICENSE` |
| `gsap-3.15.1/` | https://github.com/greensock/GSAP (npm `gsap@3.15.1`) | GSAP Standard "no charge" license, https://gsap.com/standard-license. Free for commercial websites. Not for use in no-code visual animation builders that compete with Webflow. Keep the license header in each file. |
| `vanta-0.5.24/` | https://github.com/tengbao/vanta (npm `vanta@0.5.24`) | MIT, see `vanta-0.5.24/LICENSE.md` |
| `three-0.134.0/` | https://github.com/mrdoob/three.js (npm `three@0.134.0`, the version Vanta is built for) | MIT, see `three-0.134.0/LICENSE` |

React Bits (https://github.com/DavidHDev/react-bits) is used as a reference only. Its license (MIT + Commons Clause) allows its effects inside a website but not redistributing the components, so it is not copied here; effects are rebuilt inside the client site that uses them.

- `funmode-1.0/` — Fun Mode, an opt-in arcade mini game for client sites. Original code by The Academy; no third-party code.
